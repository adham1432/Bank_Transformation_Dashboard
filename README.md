Tools used: Excel, Power BI, DAX, Power Query 
Analyzed a dataset of bank transactions to extract key insights about customer behavior and 
transaction types. 
Cleaned and transformed raw data using Excel and Power Query, and performed aggregations 
withdrawals, deposit, transfer and customer segmentation. 
Created an interactive dashboard in Power BI showing transaction counts by type, total transactions 
amount depends on time, total amount withdrawn per customer, show fraud flags in table, Show 
network chip and bandwidth in fraud transaction
